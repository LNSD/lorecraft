> [!Warning]
> This is a work in progress and is not ready for production use.

A toolkit for the agent-facing documentation of a repository: the coding-rule documents, the
feature docs (specs, plans and status) and the agent skills that agents read while they work.

It covers the mechanical half of reviewing those documents: frontmatter against a schema, section
outlines against a structure spec, prose against a length budget, and skills against the Agent Skills
specification. A repository declares the rules it wants and runs one checker, instead of carrying a
standalone script per check.
