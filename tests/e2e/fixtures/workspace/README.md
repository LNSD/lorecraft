# Workspace fixture

A workspace root for the `inspect`, `check` and `check <name>` snapshot tests. This README sits
outside the scan scope, so it never appears in the output.

The skills cover each way an agent reaches one: `alpha` is a directory in `.agents/skills/`, `beta` is a
link to it, `gamma` is a link to `skills/gamma/`, outside the skills directories, and `.claude/skills` is a
link to `.agents/skills/`.
