                                                                                
 Usage: lorecraft check [OPTIONS]                                               
                                                                                
 Check every document and skill of the workspace: frontmatter, outline, length, 
 links and layout.                                                              
                                                                                
 As text, the diagnostics go to stdout, and the ungoverned subjects and a       
 summary to stderr.                                                             
                                                                                
 As JSON, one document goes to stdout.                                          
                                                                                
 --select never enables a rule its level leaves off; each such rule, and each   
 alias code, is warned of on stderr.                                            
                                                                                
 Exit 0 when no diagnostic is an error, 1 when any is, and 2 for invalid input, 
 specifications or selectors.                                                   
                                                                                
╭─ Options ────────────────────────────────────────────────────────────────────╮
│ --root          <path>       Repository root. Defaults to the nearest parent │
│                              containing docs/__meta__.                       │
│ --format        <text|json>  Output format: text or json. [default: text]    │
│ --select        <selectors>  Run only these rules: codes, code or group      │
│                              prefixes, or ALL, comma-separated or repeated.  │
│                              Defaults to ALL.                                │
│ --ignore        <selectors>  Skip these rules, unless a more specific        │
│                              selector selects them: codes, code or group     │
│                              prefixes, or ALL, comma-separated or repeated.  │
│                              Defaults to none.                               │
│ --help                       Show this message and exit.                     │
╰──────────────────────────────────────────────────────────────────────────────╯
