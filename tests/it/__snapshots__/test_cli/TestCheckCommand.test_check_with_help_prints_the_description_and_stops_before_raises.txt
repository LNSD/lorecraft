                                                                                
 Usage: lorecraft check [OPTIONS]                                               
                                                                                
 Check every document and skill of the workspace: frontmatter, outline, length, 
 links and layout.                                                              
                                                                                
 As text, the diagnostics go to stdout, and the ungoverned subjects and a       
 summary to stderr.                                                             
                                                                                
 As short, each diagnostic is one line on stdout: its path and line, severity,  
 code and message.                                                              
                                                                                
 As JSON, one compact document goes to stdout.                                  
                                                                                
 --select never enables a rule its level leaves off; each such rule, and each   
 alias code, is warned of on stderr.                                            
                                                                                
 Exit 0 when no diagnostic is an error, 1 when any is, and 2 for invalid input, 
 specifications or selectors.                                                   
                                                                                
╭─ Options ────────────────────────────────────────────────────────────────────╮
│ --root          <path>             Repository root. Defaults to the nearest  │
│                                    parent containing docs/__meta__.          │
│ --format        <text|short|json>  Output format: text prints each           │
│                                    diagnostic with its labels, help and      │
│                                    notes, short prints one line each, json   │
│                                    prints one document.                      │
│                                    [default: text]                           │

│                                    group prefixes, or ALL, comma-separated   │
│                                    or repeated. Defaults to none.            │
│ --help                             Show this message and exit.               │
