                                                                                
 Usage: lorecraft check [OPTIONS]                                               
                                                                                
 Check every document and skill of the workspace: frontmatter, outline, length, 
 links and layout.                                                              
                                                                                
 As text, each diagnostic is drawn on stdout with its source lines, labels,     
 help and notes, coloured on a terminal.                                        
                                                                                
 As short, each diagnostic is one uncoloured line on stdout: its path and line, 
 severity, code and message.                                                    
                                                                                
 The ungoverned subjects and a summary go to stderr, with the errors and        
 warnings per code prefix as text.                                              
                                                                                
 As JSON, one compact document goes to stdout.                                  
                                                                                
 --select never enables a rule its level leaves off; each such rule, and each   
 alias code, is warned of on stderr.                                            
                                                                                
 Exit 0 when no diagnostic is an error, 1 when any is, and 2 for invalid input, 
 specifications or selectors.                                                   
                                                                                
╭─ Options ────────────────────────────────────────────────────────────────────╮
│ --root          <path>             Repository root. Defaults to the nearest  │
│                                    parent containing docs/__meta__.          │
│ --format        <text|short|json>  Output format: text draws each diagnostic │
│                                    in full, short prints one line each, json │
│                                    prints one document.                      │
│                                    [default: text]                           │
│ --color         <WHEN>             Control when colored output is used.      │
│                                    auto: colour when stdout is an            │
│                                    interactive terminal, unless NO_COLOR is  │
│                                    set; FORCE_COLOR forces it.               │
│                                    always: colour even when stdout is not a  │
│                                    terminal.                                 │
│                                    never: no colour.                         │
│                                    Only the text format is coloured.         │
│                                    [default: auto]                           │
│ --select        <selectors>        Run only these rules: codes, code or      │
│                                    group prefixes, or ALL, comma-separated   │
│                                    or repeated. Defaults to ALL.             │
│ --ignore        <selectors>        Skip these rules, unless a more specific  │
│                                    selector selects them: codes, code or     │
│                                    group prefixes, or ALL, comma-separated   │
│                                    or repeated. Defaults to none.            │
│ --help                             Show this message and exit.               │
