                                                                                
 Usage: lorecraft check skills [OPTIONS] [paths]...                             
                                                                                
 Check each skill against the Agent Skills specification: its SKILL.md and its  
 other Markdown files.                                                          
                                                                                
 A skill named by its SKILL.md has that file checked alone.                     
                                                                                
 Exit 0 when clean, 1 when findings exist, and 2 for invalid input.             
                                                                                
╭─ Arguments ──────────────────────────────────────────────────────────────────╮
│   paths      <path>  Skills to check, each by a skill directory, a directory │
│                      of skills, or a SKILL.md, relative to the current       │
│                      directory; a SKILL.md checks that file alone. Defaults  │
│                      to every skill in the agents' skills directories under  │
│                      ROOT.                                                   │
╰──────────────────────────────────────────────────────────────────────────────╯
╭─ Options ────────────────────────────────────────────────────────────────────╮
│ --root          <path>       Repository root. Defaults to the nearest parent │
│                              containing docs/__meta__.                       │
│ --format        <text|json>  Output format: text or json. [default: text]    │
│ --help                       Show this message and exit.                     │
╰──────────────────────────────────────────────────────────────────────────────╯
