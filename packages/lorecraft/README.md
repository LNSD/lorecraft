# lorecraft

A toolkit for the agent-facing documentation of a repository: the coding-rule documents, the feature docs
(specs, plans and status) and the agent skills that agents read while they work.

This package is the `lorecraft` command line:

```sh
uv tool install lorecraft
lorecraft version --verbose
```

See the [repository](https://github.com/lnsd/lorecraft) for the documentation.
